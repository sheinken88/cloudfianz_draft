# Páginas de servicio y caso · 29 de octubre de 2026

Se conserva la base del draft-01: navy #0B1D3A, teal #12B5A5, blanco #FFFFFF, mint #E8F4F0 y gris #55616F; Manrope en titulares e Inter en texto. Márgenes de 80 px aprox. a 1440 px, contenedor máximo de 1280 px; lectura de 60–75 caracteres. Titulares de apertura 58–66 px en desktop y 38–42 px en móvil. Todo alineado a la izquierda.

## Servicio

La apertura mint combina el titular aprobado con evidencia de software real. Las aplicaciones se explican en filas amplias, sin convertir cada párrafo en una card. Un proyecto destacado une resultado y captura; Photonix y ADS aparecen como lecturas relacionadas. La elección de solución, el alcance, las cuatro formas independientes de contratación y las dudas de compra completan el recorrido.

```
header compartido
breadcrumb
[titular + necesidad + CTA] [captura auténtica Despegar]
[cuándo hace falta] [tres aplicaciones en filas]
[proyecto destacado con imagen] + dos proyectos relacionados
[criterio de solución] [alcance y entrega]
[auditoría / diseño / implementación / soporte]
[preguntas] + [respaldo Digifianz]
[consulta contextual]
footer compartido
```

## Caso

El proyecto es la evidencia: marca original, titular orientado al cambio y captura completa como apertura. El relato mantiene problema, decisiones, solución, resultados y evolución. Índice de anclas para navegar un texto largo; columna de títulos y columna de lectura con listas donde ayudan a comparar capacidades.

```
header compartido + breadcrumb
[logo real + titular + resumen] [contexto del proyecto]
[captura completa del cotizador]
índice de lectura
[problema] [relato]
[decisiones] [relato]
[solución] [relato + segunda captura]
[resultados] [relato + beneficios]
[evolución] [relato]
CTA contextual + servicios relacionados + footer
```

## Revisión previa a implementación

Se evita replicar la homepage en ambas páginas o usar una grilla de cards para todo. El servicio ayuda a decidir; el caso aporta prueba y contexto. Se reutilizan recursos originales y los textos vigentes de `content/`. No se agregan métricas, testimonios o logos. Contacto mantiene el destino local de la homepage hasta su siguiente etapa. La navegación y el contenido principal funcionan sin JavaScript; solo los textos cuyas páginas siguen pendientes conservan el lector provisional.
